# nrc_policy_ref — reference contract for NRC-4 / NRC-5

Vendored from `nrc_policy_ref-v0.3.zip` (the policy deliverable) and run by this repo's pytest.
Changes from the delivered copy: the bundle is read from
`scripts/data/nrc-ipb-candidate-bundle-v0.3.json`, imports use `tests.nrc_policy_ref`, files are
read as UTF-8, and the code is reformatted by ruff. The bundle builder and PDF scripts stay with the
policy deliverable. `scripts/import_policy_bundle.py` and `tests/test_policy_bundle_import.py` check
the runtime import against this contract.

Reference implementation of the policy-bundle contract in `nrc-ipb-candidate-bundle-v0.3.json`. Not production code; a spec the real loader and validators must match.

- `bundle.schema.json` — JSON Schema for bundle v0.3.
- `contract.py` — `load_bundle` (schema, content sha256, quotation sha256, runtime activation guard), `select_rules` (structured predicates only; semantic hits can add advisory rules, never remove mandatory ones), `evaluate` (deterministic checks + readiness aggregation), `build_graph` (GraphRAG nodes/edges; only APPROVED exceptions become edges).
- `fixtures/labelled_fixtures.json` — 41 labelled cases (generated by `make_fixtures.py`).
- `test_contract.py` — 70 tests.

Semantic judgments (model calls) are inputs, stubbed by labelled results: the tests prove the contract, not model quality.

Run from the parent folder:

    pip install jsonschema==4.23.0 pytest==8.3.4
    python -m pytest nrc_policy_ref -q

`test_contract.py` reads the bundle from `/mnt/user-data/outputs/`; change `BUNDLE_PATH` to your copy.
